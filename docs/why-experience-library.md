# 个人经验库：让 AI Agent 真正陪你成长

## 1. AI Agent 的记忆困境

AI Agent 正在重塑我们的工作方式，但在「记忆」这件事上，它们有着根本性的缺陷。

### 上下文压缩导致信息丢失

每个 Session 的上下文窗口有限。当对话变长，系统会自动压缩历史信息——而压缩意味着取舍。重要的调试经验、踩过的坑、好不容易找到的 workaround，可能在某次压缩中悄无声息地消失。你以为它记得，但它已经忘了。

### 跨 Session 经验断裂

关掉终端，一切归零。上一个 Session 中积累的上下文、达成的共识、发现的边界条件，在新 Session 中荡然无存。你不得不重复解释同样的背景，重复犯同样的错误。AI Agent 对你来说永远是「新同事」——每次都要从头认识。

### 输出不稳定，缺乏迭代优化

因为经验无法累积，AI Agent 的输出质量波动剧烈。同一个问题，今天的方案和昨天的方案可能完全不同，甚至会互相矛盾。它无法在「上次做得不错」的基础上继续优化，也无法从「上次踩了坑」中吸取教训。每一次都是重新开始，没有迭代，没有进步。

### 经验被困在单一工具中

所有经验局限在一台物理机、一个工具上。当你从 Claude Code 切换到 Cursor，从 ChatGPT 换到 Copilot，之前的经验无法迁移。工具在快速迭代，市场在不断洗牌——而你的经验和知识，本应属于你自己，却被绑死在了某个具体产品里。更换工具的代价巨大，因为你丢失的不只是习惯，还有所有积累下来的知识。

## 2. 我们需要一个什么

我们需要一个**可跨 AI Agent 的个人经验库**。

它不是某个工具的附属功能，而是独立于任何 AI Agent 的基础设施。无论你使用 Claude Code、Cursor、Copilot 还是任何未来的 AI 工具，经验库始终在那里，持续积累，持续优化。

### 经验随你走，不随工具走

经验库的所有权属于你。它存储的是你解决问题的方法、你项目的特殊约定、你踩过的坑和找到的解法。这些知识不会因为换了一个编辑器、换了一个 AI 助手就消失。工具是过客，经验是你的资产。

### 持续迭代，不断优化

经验库不是只读的档案柜，而是一个可以更新、迭代的活系统。当你发现更好的方案时，更新旧经验；当经验过时时，删除它。每一次交互都在让经验库变得更好，AI Agent 的输出也因此越来越贴合你的需求和偏好。

### 让 AI Agent 真正陪你成长

有了经验库，AI Agent 不再是每次都从零开始的陌生人。它知道你之前是怎么解决类似问题的，知道你的项目有什么特殊约定，知道哪些坑不要再踩。它终于可以像一个真正的搭档一样，在持续协作中不断进步。

## 3. canned-exp 实现了什么

canned-exp 是一个开源的个人经验库，通过 MCP（Model Context Protocol）协议为 AI Agent 提供经验检索和存储能力。

### 核心能力

**语义检索**：基于向量匹配，用自然语言描述问题即可命中相关经验。即使用词不同，只要语义相近就能找到——因为经验的价值在于「问题的本质」而非「关键词的巧合」。

**结构化管理**：每条经验包含内容、标题、标签、来源等信息。标签体系支持领域+问题模式的复合分类（如 `go-context`、`mcp-sse`），确保检索精准。

**智能去重**：保存新经验时自动检测相似内容，避免重复积累。可以选择强制保存或跳过，让经验库保持精炼。

### 通用接入

通过 MCP 协议，任何支持 MCP 的 AI Agent 都能直接使用经验库。SSE 传输层使得经验库可以部署在远程服务器上，所有设备共享同一份经验。同时提供 REST 端点，方便脚本和 Hook 集成。

### 安全保障

经验库可能包含敏感的项目信息，安全性是第一优先级。

**TOTP 认证**：支持 Google Authenticator 等标准验证器，登录获取 session token，24 小时有效期。每个服务（如 Claude Code、Cursor）拥有独立的 session，新登录自动吊销旧 session，确保同一服务只有一个活跃 token。

**分层权限**：
- 本地回环地址免认证——开发调试零摩擦
- API Key 只读访问——用于 Hook 脚本等自动化场景，只能检索，不能修改
- Session Token 全权限——通过 TOTP 登录获取，支持完整的读写操作

**公网安全**：所有端点（MCP SSE + REST）在公网环境下均需认证，未认证请求返回 401。服务重启自动清空所有 session，强制重新认证。

---

经验是 AI 时代最被低估的个人资产。canned-exp 让你的经验不再随工具更迭而流失，让 AI Agent 真正成为随你成长的长期搭档。
